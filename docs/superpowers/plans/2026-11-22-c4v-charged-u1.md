## Review Focus

These are the input classes that the spec implies but does not test by name, most likely first. Each line names the task whose test pins it.

1. **chi too small for a mirror pair.** `ctm_tensor_c4v(A, chi=1)` where the top value of the corner belongs to a pair (q, dual(q)) must raise a `ValueError` that names chi and says "Use chi >= 2". An empty bond or an `IndexError` is wrong. Pinned by Task 2, `test_projector_refuses_a_chi_that_splits_the_top_pair`.
2. **A sublattice-rotated gate.** A user who passes `sublattice_rotate_gate(H)` (the 1x1 AFM convention) must get the dense C4v energy for that gate: −0.615764147988 at chi=8 on the #762 fixture (measured, both paths, |ΔE| 3.3e-16). Pinned by Task 6, test 7, which runs both gates.
3. **An env from another CTM.** `compute_energy_ctm_tensor(A_charged, env)` with a dense env, with an env whose D² leg is dualled, or with an env from the general `ctm_tensor` must raise a `ValueError` that says the env was not built for this A. A silent wrong energy is wrong. Pinned by Task 5: two core tests and the algorithm test 10.
4. **Z_n with n even.** The self-partner charge n/2 sits next to mirror pairs. Its block is ranked by |λ| and keeps its sign; it needs no partner. Z4 `[0, 2]` alone (all self-dual) stays on the old path. Pinned by Task 2 (synthetic Z4), Task 6 (Z4 at chi 7 and 10, with one and two charge-2 states on `c_a`, against dense C4v), and the Task 6 routing case `z4_self_dual`.

```python
"""Shared fixtures for the charged C4v CTM tests (#762, #763).

``test_c4v_staggered.py`` (core) and ``test_ctm_tensor_c4v.py`` (algorithm)
import from here.  The probes here do not use the code under test as their
oracle.
"""

from __future__ import annotations

import jax
import jax.numpy as jnp
import numpy as np

from tenax.algorithms.ipeps import symmetrize_c4v
from tenax.core.index import FlowDirection, TensorIndex
from tenax.core.tensor import SymmetricTensor


def c4v_fixture(sym, vc, pc, key=42):
    """A real C4v site tensor in the charged C4v layout; D = len(vc), d = len(pc).

    u, l are OUT with charges ``vc``; d, r are IN with ``sym.dual(vc)``; phys is
    IN with ``pc``.  The four faces then carry the same flow-weighted charge at
    each position, so ``symmetrize_c4v`` keeps the block structure.  The data
    is random (``key``), projected onto the C4v-invariant subspace.
    """
    vc = np.asarray(vc, dtype=np.int32)
    vd = sym.dual(vc)
    pc = np.asarray(pc, dtype=np.int32)
    indices = (
        TensorIndex.from_charges(sym, vc.copy(), FlowDirection.OUT, label="u"),
        TensorIndex.from_charges(sym, vd.copy(), FlowDirection.IN, label="d"),
        TensorIndex.from_charges(sym, vc.copy(), FlowDirection.OUT, label="l"),
        TensorIndex.from_charges(sym, vd.copy(), FlowDirection.IN, label="r"),
        TensorIndex.from_charges(sym, pc.copy(), FlowDirection.IN, label="phys"),
    )
    raw = SymmetricTensor.random_normal(indices, jax.random.PRNGKey(key))
    data = symmetrize_c4v(jnp.asarray(raw.todense()))
    return SymmetricTensor.from_dense(data, indices)


def leg(T, label):
    """The index of ``T`` with this label."""
    return T.indices[T.labels().index(label)]


def pairs(x, y):
    """True when the legs ``x`` and ``y`` contract: opposite flows, same charges."""
    return x.flow != y.flow and np.array_equal(x.charges, y.charges)
```

```python
def _layout(sym, faces, pc, key=0):
    """A random tensor with the face layout ``faces = ((label, flow, charges), ...)``."""
    indices = tuple(
        TensorIndex.from_charges(sym, np.asarray(q, dtype=np.int32), flow, label=label)
        for label, flow, q in faces
    )
    phys = TensorIndex.from_charges(
        sym, np.asarray(pc, dtype=np.int32), IN, label="phys"
    )
    return SymmetricTensor.random_normal((*indices, phys), jax.random.PRNGKey(key))


@functools.cache

    """The site tensors of these tests, each built once."""
    u1, z4 = U1Symmetry(), ZnSymmetry(4)

def _conserves(sym, key, indices):
    """True when the block key fuses to the identity charge, weighted by flow."""
    parts = [
        sym.flow_charge(idx.flow, np.asarray([q], dtype=np.int32))
        for q, idx in zip(key, indices)
    ]
    return int(sym.fuse_many(parts)[0]) == sym.identity()

@pytest.mark.parametrize("name", ["762", "z3"])
def test_negate_is_a_data_preserving_involution(name):
    A = _site(name)
    sym = A.indices[0].symmetry
    B = _negate_charges(A)
    for ia, ib in zip(A.indices, B.indices):
        assert (ib.label, ib.flow) == (ia.label, ia.flow)
        np.testing.assert_array_equal(ib.charges, sym.dual(ia.charges))
    np.testing.assert_array_equal(np.asarray(B.todense()), np.asarray(A.todense()))
    assert all(_conserves(sym, key, B.indices) for key in B.blocks)
    A2 = _negate_charges(B)
    assert set(A2.blocks) == set(A.blocks)
    for key, block in A.blocks.items():
        np.testing.assert_array_equal(np.asarray(A2.blocks[key]), np.asarray(block))
```

```python
"""Charge helpers for C4v input whose virtual charges are not self-dual.

A bosonic C4v ``SymmetricTensor`` ``A`` whose four faces carry the same
flow-weighted charge at each position, and whose virtual charges are not all
self-dual, describes the 2-sublattice state ``(A, negate(A))``: ``A`` on the
sites with x + y even and ``_negate_charges(A)`` on the others (#762).
peps-torch builds its U(1) C4v state the same way
(``IPEPS_ABELIAN_C4V.get_bipartite_state``; Hasik, Poilblanc and Becca,
SciPost Phys. 10, 012 (2021)).

This is a leaf module: it imports only ``tenax.core``, so the energy routine
can use it without importing the sweep.  Every charge inversion goes through
``sym.dual`` (in ``_dual``) and every flow weighting through
``sym.flow_charge``; no code here writes ``-q`` (#734).
"""

from __future__ import annotations

__all__ = [
    "_C4V_FACES",
    "_dual",
    "_dual_charge",
    "_first_unequal_c4v_face",
    "_is_charged_c4v",
    "_negate_charges",
    "_pairs",
]

import numpy as np

from tenax.core.index import TensorIndex
from tenax.core.symmetry import BaseSymmetry
from tenax.core.tensor import SymmetricTensor, Tensor

# The four virtual faces of a site tensor; the C4v group permutes them.
_C4V_FACES = ("u", "d", "l", "r")


def _dual(sym: BaseSymmetry, charges) -> np.ndarray:
    """``sym.dual`` of a charge array, as int32: the one charge inversion here."""
    return sym.dual(np.asarray(charges, dtype=np.int32))


def _dual_charge(sym: BaseSymmetry, q: int) -> int:
    """``sym.dual`` of a single charge."""
    return int(_dual(sym, [q])[0])


def _pairs(x: TensorIndex, y: TensorIndex) -> bool:
    """True when the legs ``x`` and ``y`` contract: opposite flows, same charges."""
    return x.flow != y.flow and np.array_equal(x.charges, y.charges)


def _negate_charges(T: Tensor) -> SymmetricTensor:
    """Replace every charge q of ``T`` by ``sym.dual(q)``: index charges and block keys.

    Flows, labels and block data are kept, so ``todense()`` does not change.
    ``_negate_charges(A)`` is the tensor on the other sublattice of a charged
    C4v state.  Cost O(blocks), no ``todense()``.  The new indices are plain:
    the fusion metadata of fused legs is dropped.

    Raises:
        TypeError: ``T`` is not a ``SymmetricTensor``.
        NotImplementedError: ``T`` has a fermionic symmetry.  ``ctm_tensor_c4v``
            densifies fermionic input, so no caller negates one.
    """
    if not isinstance(T, SymmetricTensor):
        raise TypeError(
            f"_negate_charges needs a SymmetricTensor, got {type(T).__name__}"
        )
    sym = T.indices[0].symmetry
    if sym.is_fermionic:
        raise NotImplementedError(
            "_negate_charges: fermionic symmetries are not supported"
        )
    indices = tuple(
        TensorIndex.from_charges(
            sym, _dual(sym, idx.charges), idx.flow, label=idx.label
        )
        for idx in T.indices
    )
    blocks = {
        tuple(int(q) for q in _dual(sym, key)): block
        for key, block in T.blocks.items()
    }
    return SymmetricTensor(blocks, indices)


def _first_unequal_c4v_face(A: SymmetricTensor) -> str | None:
    """The first face whose flow-weighted charges differ from those of face ``u``.

    The faces are compared position by position, not as multisets:
    ``symmetrize_c4v`` permutes the four virtual legs, so it keeps the block
    structure only when all four faces carry the same flow-weighted charge at
    each position.  Returns ``None`` when they do.  ``A`` must have the labels
    ``u``, ``d``, ``l`` and ``r``.
    """
    sym = A.indices[0].symmetry
    faces = {idx.label: idx for idx in A.indices if idx.label in _C4V_FACES}
    ref = sym.flow_charge(faces["u"].flow, faces["u"].charges)
    for face in ("d", "l", "r"):
        fc = sym.flow_charge(faces[face].flow, faces[face].charges)
        if not np.array_equal(fc, ref):
            return face
    return None


def _is_charged_c4v(A: Tensor) -> bool:
    """True for the input that ``ctm_tensor_c4v`` sends to the 2-sublattice sweep.

    That is a bosonic ``SymmetricTensor`` with the labels u, d, l, r and phys,
    four faces with equal flow-weighted charges at each position, and at least
    one virtual charge q with ``q != sym.dual(q)`` at its position.  Self-dual
    charges (Z2, all-zero U(1), Z4 charge 2) give False, and so does a tensor
    that conserves the uniform U(1) (its d face carries the dual of the u
    face).  Reads index metadata only, so it is safe under ``jit`` and
    ``grad``.
    """
    if not isinstance(A, SymmetricTensor):
        return False
    if not {*_C4V_FACES, "phys"} <= set(A.labels()):
        return False
    sym = A.indices[0].symmetry
    if sym.is_fermionic:
        return False
    if _first_unequal_c4v_face(A) is not None:
        return False
    return any(
        not np.array_equal(_dual(sym, idx.charges), idx.charges)
        for idx in A.indices
        if idx.label in _C4V_FACES
    )
```

```python
"""The 2-sublattice C4v CTM sweep for charged C4v input (#762, #763).

A bosonic C4v ``SymmetricTensor`` ``A`` whose virtual charges are not all
self-dual describes the 2-sublattice state ``(A, negate(A))`` (see
``_ctm_c4v_charges``).  This module runs its CTM with one corner and one
edge, as ``_c4v_sweep`` does for self-dual input, and keeps the symmetry and
the lattice mirror exact.

The state, in the C1/T1 orientation of the #905 flow table:

- ``C``: the corner of an A-site, legs ``(c_a IN, c_b OUT)``.
- ``T``: the edge above an A-site (its first site is a B-site), legs
  ``(t_l IN, D2 OUT, t_r OUT)``; ``D2`` pairs with the ``u2`` face of ``a``.
- ``a``: the double layer of ``A`` (``_build_double_layer_tensor``).

One step enlarges the corner as ``_c4v_sweep`` does, truncates it with one
block projector (an SVD per mirror pair of blocks, an eigh per self-partner
block, one ranking that never splits a pair), and sets ``C_new = P^T Q P``
and ``T_new = negate(P^T (T a) P)``, which is again the edge above an
A-site.  Design: ``docs/superpowers/specs/2026-11-22-c4v-charged-u1-design.md``.
"""

from __future__ import annotations

__all__ = [
    "_c4v_staggered_projectors",
]

import jax.numpy as jnp
import numpy as np

from tenax.algorithms._ctm_c4v_charges import _dual, _dual_charge
from tenax.algorithms._ctm_tensor_init import IN, OUT
from tenax.core.index import TensorIndex
from tenax.core.tensor import SymmetricTensor
from tenax.linalg import _dense_svd

# Values below this fraction of the largest are dropped: the cutoff of the SVD
# projector in ``_ctm_projector.py``.
_REL_CUTOFF = 1e-14


def _c4v_staggered_projectors(
    Qf: SymmetricTensor, chi: int
) -> tuple[SymmetricTensor, SymmetricTensor]:
    """The block projector of the 2-sublattice sweep: ``(P_left, P_right)``.

    ``Qf`` is the enlarged corner with the legs ``fused`` (IN, bottom face)
    and ``col`` (OUT, right face).  Both faces carry the same flow-weighted
    charges, so ``col`` holds the duals of the ``fused`` charges, every block
    has the key (q, q), and block q joins the fused states of charge q with
    those of charge ``sym.dual(q)``.  The lattice mirror maps block q to
    block ``sym.dual(q)``, transposed, with the same singular values.

    - A mirror pair (q, dual(q)), q != dual(q): one SVD, Q_q = U S V^T.  The
      projector takes the kept columns of U in sector q and the same columns
      of V in sector dual(q).
    - A self-partner block, q == dual(q) (0 for U(1); also n/2 for Z_n with
      n even): eigh of the symmetrised block, ranked by |lambda|.

    All values are ranked together; a pair value counts once in each of its
    two sectors.  The chi largest are kept, except that a cut between the
    two copies of one pair value drops both (the dimension is then chi - 1).
    Values below ``_REL_CUTOFF`` of the largest are dropped.  This is the
    ranking of the dense eigh of ``_c4v_sweep``: the dense Q has eigenvalues
    +s and -s for each pair value s.

    ``P_left`` is ``(fused OUT, chi_new IN)`` and contracts with the fused
    face; ``P_right`` is ``(col IN, chi_new_r OUT)`` and contracts with the
    col face.  They hold the same arrays, one dense P on both faces; only the
    keys and flows differ.

    Raises:
        RuntimeError: the two faces of ``Qf`` do not carry the same
            flow-weighted charges (not a 2-sublattice corner).
        ValueError: nothing survives the cutoff (a zero corner), or chi = 1
            and the largest value belongs to a mirror pair.
    """
    labels = Qf.labels()
    fpos, cpos = labels.index("fused"), labels.index("col")
    fused, col = Qf.indices[fpos], Qf.indices[cpos]
    sym = fused.symmetry
    if not np.array_equal(col.charges, _dual(sym, fused.charges)):
        raise RuntimeError(
            "charged C4v projector: the two faces of the enlarged corner do not "
            "carry the same flow-weighted charges, so the env is not a "
            "2-sublattice env"
        )
    # Block (q, q): rows are the fused states of charge q, columns the col
    # states of charge q, which are the fused states of charge dual(q).
    mats = {
        int(key[fpos]): (block if fpos < cpos else block.T)
        for key, block in Qf.blocks.items()
    }

    decomp, cands, done = {}, [], set()
    for q in sorted(mats):
        if q in done:
            continue
        qd = _dual_charge(sym, q)
        M = mats[q]
        if qd == q:
            # Self-partner block: symmetric by the mirror; rank by |lambda|.
            lam, W = jnp.linalg.eigh(0.5 * (M + M.T))
            decomp[q] = ("self", W, None)
            for n, v in enumerate(np.abs(np.asarray(lam))):
                cands.append((float(v), q, n, 0))
            done.add(q)
        else:
            # Mirror pair (q, dual(q)): one SVD.  Each value has two copies,
            # one state in sector q and one in sector dual(q).
            U, S, Vh = _dense_svd(M, full_matrices=False)
            decomp[q] = ("pair", U, Vh.T)
            for n, v in enumerate(np.asarray(S)):
                cands += [(float(v), q, n, 0), (float(v), q, n, 1)]
            done.update((q, qd))

    vmax = max((c[0] for c in cands), default=0.0)
    alive = sorted(
        (c for c in cands if c[0] > 0.0 and c[0] >= _REL_CUTOFF * vmax),
        key=lambda c: (-c[0], c[1], c[2], c[3]),
    )
    if not alive:
        raise ValueError("charged C4v projector: the enlarged corner is zero")

    copies: dict[tuple[int, int], int] = {}
    for _v, q, n, _copy in alive[:chi]:
        copies[(q, n)] = copies.get((q, n), 0) + 1
    keep: dict[int, list[int]] = {}
    for (q, n), count in copies.items():
        # A cut between the two copies of a pair value would keep one state
        # of a mirror pair without its partner: drop both.
        if decomp[q][0] == "pair" and count == 1:
            continue
        keep.setdefault(q, []).append(n)
    if not keep:
        raise ValueError(
            f"ctm_tensor_c4v: chi={chi} keeps no state of the charged C4v "
            "corner. Its largest value belongs to a mirror pair (q, dual(q)), "
            "which needs two states. Use chi >= 2."
        )

    cols = {}
    for q in sorted(keep):
        kind, U, V = decomp[q]
        ns = sorted(keep[q])
        cols[q] = U[:, ns]
        if kind == "pair":
            cols[_dual_charge(sym, q)] = V[:, ns]

    # One array per sector on both faces.  On the col face, the states of
    # fused charge x have col charge dual(x), and so does their chi_new_r leg.
    left, right, chi_charges = {}, {}, []
    for x in sorted(cols):
        xd = _dual_charge(sym, x)
        left[(x, x)] = cols[x]
        right[(xd, xd)] = cols[x]
        chi_charges += [x] * cols[x].shape[1]
    chi_charges = np.asarray(chi_charges, dtype=np.int32)
    P_left = SymmetricTensor(
        left,
        (
            fused.flip_flow(),
            TensorIndex.from_charges(sym, chi_charges, IN, label="chi_new"),
        ),
    )
    P_right = SymmetricTensor(
        right,
        (
            col.flip_flow(),
            TensorIndex.from_charges(
                sym, _dual(sym, chi_charges), OUT, label="chi_new_r"
            ),
        ),
    )
    return P_left, P_right
```

```python
def _leg(T: Tensor, label: str) -> TensorIndex:
    """The index of ``T`` with this label."""
    return T.indices[T.labels().index(label)]


def _c4v_staggered_enlarged_corner(C: Tensor, T: Tensor, a: Tensor) -> Tensor:
    """Q = C · T_top · T_left · a, with its two open faces fused.

    The contraction of step 1 of ``_c4v_sweep``, which stays unchanged:
    C.c_b joins the top edge's t_l and C.c_a the left edge's t_r; the top
    edge's D2 is a.u2, the left edge's is a.l2.  The bottom face (the open
    chi leg of T_left, a.d2) is fused into ``fused`` (IN); the right face
    (the open chi leg of T_top, a.r2) into ``col`` (OUT).
    """
    Q = contract(C.relabel("c_b", "t_l"), T)  # (c_a, D2, t_r)
    Q = Q.relabels({"D2": "u2", "t_r": "o_r"})
    T_left = T.relabels({"t_r": "c_a", "D2": "l2", "t_l": "o_d"})
    Q = contract(Q, T_left)  # (u2, o_r, o_d, l2)
    Q = contract(Q, a)  # (o_r, o_d, d2, r2)
    Qf = _fuse_pair_by_label(Q, "o_d", "d2", "fused", IN)
    return _fuse_pair_by_label(Qf, "o_r", "r2", "col", OUT)  # (fused, col)


def _c4v_staggered_initial_state(
    a: SymmetricTensor,
) -> tuple[SymmetricTensor, SymmetricTensor]:
    """The trace boundary: C = [1], and T the ket-bra identity on D2.

    C is 1 x 1 with the identity charge.  T has chi legs of dimension 1 with
    the identity charge and the full D2 index that pairs with ``a.u2``; its
    data is the ket-bra identity delta_kk', whose nonzero entries all carry
    the identity charge.  The state satisfies I1-I3.
    """
    u2 = _leg(a, "u2")
    sym = u2.symmetry
    e = np.asarray([sym.identity()], dtype=np.int32)
    C = SymmetricTensor(
        {(int(e[0]), int(e[0])): jnp.ones((1, 1), dtype=a.dtype)},
        (
            TensorIndex.from_charges(sym, e, IN, label="c_a"),
            TensorIndex.from_charges(sym, e, OUT, label="c_b"),
        ),
    )
    D = int(round(np.sqrt(u2.dim)))
    data = np.zeros((1, D * D, 1))
    data[0, np.arange(D) * (D + 1), 0] = 1.0  # delta_kk'; u2 is fused ket-major
    T = SymmetricTensor.from_dense(
        jnp.asarray(data, dtype=a.dtype),
        (
            TensorIndex.from_charges(sym, e, IN, label="t_l"),
            u2.flip_flow().relabel("D2"),
            TensorIndex.from_charges(sym, e, OUT, label="t_r"),
        ),
    )
    return C, T


def _check_c4v_staggered_invariants(
    C: SymmetricTensor,
    T: SymmetricTensor,
    a: SymmetricTensor,
    a_B: SymmetricTensor,
) -> None:
    """Check the charge invariants of the 2-sublattice state.

    - I1: the C-T chi bonds and the T.D2-a.u2 bond pair opposite flows with
      identical charges.
    - I2: the two legs of C carry the same flow-weighted charges at each
      position, and so do the two chi legs of T; each chi leg holds as many
      states of charge q as of ``sym.dual(q)``.
    - I3: ``negate(T)``, the edge above a B-site, pairs with ``a_B``, the
      double layer of the B-site tensor.

    Index metadata only.

    Raises:
        RuntimeError: the message starts with the invariant that fails.
    """
    sym = _leg(C, "c_a").symmetry

    def s(X, label):
        idx = _leg(X, label)
        return sym.flow_charge(idx.flow, idx.charges)

    if not (
        _pairs(_leg(C, "c_b"), _leg(T, "t_l"))
        and _pairs(_leg(C, "c_a"), _leg(T, "t_r"))
    ):
        raise RuntimeError("I1: a C-T chi bond does not pair")
    if not _pairs(_leg(T, "D2"), _leg(a, "u2")):
        raise RuntimeError("I1: T.D2 does not pair with a.u2")
    if not np.array_equal(s(C, "c_a"), s(C, "c_b")):
        raise RuntimeError("I2: the legs of C carry different flow-weighted charges")
    if not np.array_equal(s(T, "t_l"), s(T, "t_r")):
        raise RuntimeError(
            "I2: the chi legs of T carry different flow-weighted charges"
        )
    for X, label in ((C, "c_a"), (T, "t_l")):
        charges = s(X, label)
        for q in set(charges.tolist()):
            qd = _dual_charge(sym, q)
            if np.sum(charges == q) != np.sum(charges == qd):
                raise RuntimeError(
                    f"I2: leg {label} holds {int(np.sum(charges == q))} states "
                    f"of charge {q} but {int(np.sum(charges == qd))} of its "
                    f"mirror partner {qd}"
                )
    if not _pairs(_leg(_negate_charges(T), "D2"), _leg(a_B, "u2")):
        raise RuntimeError("I3: negate(T).D2 does not pair with a_B.u2")


def _c4v_staggered_sweep(
    C: SymmetricTensor, T: SymmetricTensor, a: SymmetricTensor, chi: int
) -> tuple[SymmetricTensor, SymmetricTensor]:
    """One step of the 2-sublattice C4v sweep; returns ``(C_new, T_new)``.

    C_new = P^T Q P is the enlarged corner projected on both faces.  T·a is
    the edge above a B-site; projected on both faces and negated, it is the
    edge above an A-site again.  Both are normalised by ``max_abs``, as in
    ``_c4v_sweep``.
    """
    Qf = _c4v_staggered_enlarged_corner(C, T, a)
    P_left, P_right = _c4v_staggered_projectors(Qf, chi)
    C_new = contract(contract(P_left, Qf), P_right)
    C_new = C_new.relabels({"chi_new": "c_a", "chi_new_r": "c_b"})

    T_with_a = contract(T.relabel("D2", "u2"), a)  # (t_l, t_r, d2, l2, r2)
    Tg = _fuse_pair_by_label(T_with_a, "t_l", "l2", "fl", IN)
    Tg = _fuse_pair_by_label(Tg, "t_r", "r2", "fr", OUT)  # (fl, d2, fr)
    T_new = contract(P_left.relabel("fused", "fl"), Tg)  # (chi_new, d2, fr)
    T_new = contract(T_new, P_right.relabel("col", "fr"))  # (chi_new, d2, chi_new_r)
    T_new = _negate_charges(T_new).relabels(
        {"chi_new": "t_l", "d2": "D2", "chi_new_r": "t_r"}
    )

    C_new = C_new * (1.0 / (C_new.max_abs() + 1e-15))
    T_new = T_new * (1.0 / (T_new.max_abs() + 1e-15))
    return C_new, T_new
```

```python
def _c4v_staggered_to_full_env(
    C: SymmetricTensor, T: SymmetricTensor
) -> CTMTensorEnv:
    """The eight env tensors around an A-site, with the #905 flows.

    Relabels and single-leg duals only.  A dual keeps the flow-weighted
    charges, and I2 makes the two legs of C, and the two chi legs of T, carry
    the same ones, so every bond pairs once the flows are set:

    - C1..C4 are C, with ``c_a`` on the IN leg and ``c_b`` on the OUT leg.
    - T1 and T4 are T; T2 and T3 are T with the D2 leg dualled (``r2`` and
      ``d2`` are IN in the #905 table).
    - The chi joins follow the 2-site RDM code (``_rdm2x1_tensor_2site``,
      ``_rdm1x2_tensor_2site``): C1.c1_d joins T4.t4_d.

    Unlike ``_c4v_to_full_env``, every chi bond pairs opposite flows, and so
    do the bonds from env to ``negate(env)`` in the 2-site energy.  The
    fields come out in the documented leg order.
    """
    env = CTMTensorEnv(
        C1=C.relabels({"c_a": "c1_d", "c_b": "c1_r"}),
        C2=C.relabels({"c_a": "c2_l", "c_b": "c2_d"}),

    than ``conv_tol`` (``_ctm_sv_diff`` with the forced-rank floor of #903),
    or for ``max_iter`` sweeps.  ``ctm_tensor_c4v`` validates ``A`` first.
    """
```

```python
def corner_edge(env):
    """The corner and the edge of a C4v env, with the sweep's labels.

    Inverts the C1/T1 relabel of ``_c4v_to_full_env`` and of
    ``_c4v_staggered_to_full_env``.

    T = env.T1.relabels({"t1_l": "t_l", "u2": "D2", "t1_r": "t_r"})

def norm_sv(C):
    """The singular values of the chi x chi corner, normalised to sum 1."""
    s = np.asarray(_dense_svd(C.todense(), compute_uv=False))
    return s / s.sum()


def sv_gap(s1, s2):
    """The largest difference of two spectra; the shorter is padded with zeros."""
    n = max(s1.size, s2.size)
    return float(
        np.max(np.abs(np.pad(s1, (0, n - s1.size)) - np.pad(s2, (0, n - s2.size))))
    )


def cut_gap(Qf, chi):
    """The relative gap at the cut, (s[chi-1] - s[chi]) / s[chi-1].

    s holds the |eigenvalues| of the symmetrised dense enlarged corner, sorted
    down: a mirror-pair value s appears as +s and -s, a self-partner value
    once.  That is the ranking of both C4v sweeps.  The dense Q is
    (chi D^2) x (chi D^2): small at the D and chi of the tests.
    """
    M = np.asarray(Qf.todense())
    s = np.sort(np.abs(np.linalg.eigvalsh(0.5 * (M + M.T))))[::-1]
    return float((s[chi - 1] - s[chi]) / s[chi - 1])


def charged_block_ratio(Qf):
    """The largest singular value of a charged block over that of all blocks."""
    sym = Qf.indices[0].symmetry
    top = charged = 0.0
    for key, block in Qf.blocks.items():
        q = np.asarray([key[0]], dtype=np.int32)
        value = float(np.linalg.norm(np.asarray(block), 2))
```

```markdown
**Charged input.** A bosonic ``SymmetricTensor`` is C4v input only when its
four faces carry the same flow-weighted charge at each position: ``u``, ``l``
OUT with charges ``q``, and ``d``, ``r`` IN with ``sym.dual(q)``. Any other
layout raises ``ValueError``. A tensor that conserves the uniform U(1) (``d``
IN with the charges of ``u``) is not C4v input; use ``ctm_tensor``. If a
virtual charge is not self-dual (U(1) ``[-1, 1]``, or Z3 charge 1), the bonds
conserve the staggered U(1), and ``A`` describes the 2-sublattice state
``(A, negate(A))``. ``negate`` replaces each charge ``q`` with
``sym.dual(q)`` and keeps the data, so this is the uniform state of
``todense(A)``. peps-torch builds its U(1) C4v state the same way (Hasik,
Poilblanc and Becca, SciPost Phys. 10, 012 (2021)). ``ctm_tensor_c4v`` runs a
2-sublattice sweep on such input (#762, #763), and
``compute_energy_ctm_tensor`` measures the 2-sublattice state.

| Input | Sweep |
|---|---|
| ``DenseTensor`` | C4v sweep |
| fermionic ``SymmetricTensor`` | densified, then the C4v sweep |
| bosonic ``SymmetricTensor``, self-dual charges (Z2, all-zero U(1), Z4 charge 2) | C4v sweep |
| bosonic ``SymmetricTensor``, a charge that is not self-dual | 2-sublattice sweep |

- On charged input, ``projector_method`` must be ``"eigh"`` and the data must
  be real; otherwise ``NotImplementedError``.
- ``compute_energy_ctm_tensor`` raises ``ValueError`` for a charged ``A`` with
  an env that was not built for it. An example is an env from the general
  ``ctm_tensor``, which does not support charged C4v input yet (#1210).
- Cost, on a charged D=2 U(1) state (the #762 fixture, CPU,
  ``conv_tol=1e-10``): the 2-sublattice sweep took 12 s at chi=8 (54 sweeps)
  and 30 s at chi=16 (164 sweeps). ``ctm_tensor_c4v`` on ``todense(A)`` took
  1.6 s and 1.8 s, and the energies agree to 4e-10. At D=2, the block
  bookkeeping costs more than the blocks save.
- A dense CTM is not always a reference for a charged state: its truncation
  does not keep the (q, ``sym.dual(q)``) pairs exact. On a monomer-dimer U(1)
  state (``vc = [0, 1]``) at chi=8, the energies of the dense ``ctm_tensor`` and
  of the block-sparse ``ctm_tensor_2site(A, negate(A))`` differ by 5.1e-2.
```
